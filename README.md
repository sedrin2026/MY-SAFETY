# MY SAFE v1

自分専用の暗号化パスワード管理PWAの第1版です。

## 重要
- 本版は「セキュリティ設計の試作」です。
- 本物の銀行情報・カード情報を入れる前に、必ずダミーデータでテストしてください。
- マスターパスワードを忘れても復元できる仕組みはまだありません。
- バックアップ/復元機能はまだありません。
- CVVは保存できるUIになっていますが、実運用では保存しない選択を強く検討してください。

## 保存方式
- サーバー通信なし
- Supabase等の外部DBなし
- IndexedDBに暗号化データを保存
- AES-GCM 256-bit
- PBKDF2-SHA-256（600,000 iterations）で鍵導出
- マスターパスワード自体は保存しません
- Service Workerはアプリ本体ファイルだけをキャッシュし、個人データはキャッシュしません

## GitHub Pages
このフォルダのファイルをリポジトリへアップロードし、GitHub Pagesで公開できます。

## 第2版で追加したいもの
- 暗号化バックアップ/復元
- データエクスポート時の再認証
- パスワード変更
- 端末内データ消去
- より厳密な画面遷移/クリップボード対策
- セキュリティレビューと実機テスト


## 注意
これはWeb/PWAとしての試作です。ブラウザのJavaScriptは公開コードなので、暗号化方式自体は第三者にも見えます。安全性は「方式を隠す」ことではなく、秘密鍵・個人データを公開しないことと、暗号を正しく使うことに依存します。

また、PWAだけでは端末OSのスクリーンショット禁止などのネイティブアプリ相当の保護を保証できません。
